# Little Kettle Valley — Media Package

Handmade art (Pillow + numpy, no generative AI) for the Little Kettle
Valley modpack: cozy Stardew-style story + Tekkit tech, Forge 1.20.1.
Colors and the 16x16 icon DSL live in `palette.json`; every asset below is
generated by a versioned `build.py` in its own subfolder, so the whole
package can be rebuilt from scratch with `tools/venv/bin/python
media/<area>/build.py`.

`overview.png` and `contact_sheet.png` (this folder) are art-director
review sheets, not deliverables themselves.

## What each subfolder's README covers
- `logo/README.md` — the original hand-drawn pixel font, the wordmark +
  edition strip layout, and the row-budget iteration notes.
- `panorama/README.md` — the continuous-strip method for the four side
  faces, the cottage/lamp/road design, and the two bugs fixed on review
  (a muddy far-hill haze color, a hairpin-shaped road).
- `icon/README.md` — the kettle badge mark and its four output sizes.
- `items/README.md` — the 16x16 DSL item batches.
